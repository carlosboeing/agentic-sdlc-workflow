# Limerick Collection: Bugs & Ballads

Seven limericks about the software bugs and developer frustrations we all know too well. Each rated on the official Bug Report Severity Scale.

---

### 1. Off-by-One Errors

```
A loop that was one index shy
Let the last element pass by
  It worked up to nine
  But ten crossed the line
Now the array waves goodbye
```

**Bug Report Severity: 3/5** — Predictable yet perennial. Will haunt you in every language.

---

### 2. Null Reference Exceptions

```
A reference that pointed at null
Made the program crash — what a lull
  No object in sight
  Just a void in the night
And a stack trace incredibly dull
```

**Bug Report Severity: 4/5** — The billion-dollar mistake claims another victim.

---

### 3. Race Conditions

```
Two threads tried to share the same state
One was early, the other was late
  They trampled the lock
  And corrupted the block
Now the data's in quantum debate
```

**Bug Report Severity: 5/5** — Only appears in production, vanishes under the debugger.

---

### 4. Memory Leaks

```
An object that never got freed
Kept allocating more than it'd need
  The heap grew and grew
  Till the RAM said adieu
And the OOM killer planted its seed
```

**Bug Report Severity: 4/5** — Slow, silent, and absolutely devastating at 3 AM.

---

### 5. Infinite Loops

```
A while loop that never would end
Kept spinning around every bend
  The CPU ran hot
  The fan gave all it got
Till the kill command proved a good friend
```

**Bug Report Severity: 3/5** — At least it is honest about what it is doing.

---

### 6. Merge Conflicts

```
Two branches diverged in the code
Each developer took their own road
  They merged with a prayer
  But conflicts were there
And the diff was an unreadable ode
```

**Bug Report Severity: 2/5** — Painful but solvable. Git blame is the real punishment.

---

### 7. "Works on My Machine"

```
"It works on my machine!" he cried
As production lay broken inside
  The Docker was wrong
  The env vars were gone
And the deployment team quietly sighed
```

**Bug Report Severity: 5/5** — The most dangerous sentence in software engineering.
