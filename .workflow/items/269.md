## Description

Add `reviewStrategy` section to `agentic-sdlc-config.json` and corresponding config reader variables to `scripts/lib/config.sh`.

**Blocked by:** none

## Files to Create/Modify

| File | Change |
|------|--------|
| `.claude/agentic-sdlc-config.json` | Add `reviewStrategy` section with `skipPerStoryReview.enabled`, `conditions.maxDifficulty`, `conditions.requireLabel` |
| `scripts/lib/config.sh` | Add `CFG_SKIP_REVIEW_ENABLED`, `CFG_SKIP_REVIEW_MAX_DIFFICULTY`, `CFG_SKIP_REVIEW_REQUIRE_LABEL` variables |

## Acceptance Criteria

- [ ] `agentic-sdlc-config.json` includes `reviewStrategy.skipPerStoryReview` section matching this schema:
  ```json
  {
    "reviewStrategy": {
      "skipPerStoryReview": {
        "enabled": true,
        "conditions": {
          "maxDifficulty": "easy",
          "requireLabel": "test-agentic-sdlc"
        }
      }
    }
  }
  ```
- [ ] Default values in config file: `enabled: true`, `maxDifficulty: "easy"`, `requireLabel: "test-agentic-sdlc"`
- [ ] `config.sh` exports `CFG_SKIP_REVIEW_ENABLED` (default: `false`), `CFG_SKIP_REVIEW_MAX_DIFFICULTY` (default: `easy`), `CFG_SKIP_REVIEW_REQUIRE_LABEL` (default: empty string)
- [ ] Config reader uses correct jq paths:
  - `.reviewStrategy.skipPerStoryReview.enabled`
  - `.reviewStrategy.skipPerStoryReview.conditions.maxDifficulty`
  - `.reviewStrategy.skipPerStoryReview.conditions.requireLabel`
- [ ] Existing config variables are unchanged
- [ ] `config.sh` header comment updated to list new variables

## Test Plan
