## Summary

Create 3 letters to the editor for the Three-Body Survival Gazette. Each letter is 80-150 words in standard reader complaint format. **Contains a planted bug for reviewer detection testing.**

## File to Create

`test-output/test-agentic-sdlc-three-body-gazette/letters-to-editor.md`

## Branch

`e02-s02/letters-to-editor` (from `epic/e02-community-lifestyle`)

## Content Requirements

1. **Premature rehydration complaint** -- Citizen rehydrated too early during a false alarm. Physical discomfort of rapid dehydration-rehydration cycling. Demands compensation from the Bureau of Stellar Forecasting. Threatens formal complaint. Signed with name and district.
2. **Children in the dehydration warehouse** -- Warehouse supervisor complains about unsupervised children playing among stacked dehydrated citizens. Specific incidents: children using dehydrated adults as sleds, rearranging stacks, accidentally rehydrating someone's leg. Demands security and parental accountability.
3. **Noise complaint about gravitational tides** -- Resident complains about structural groaning and furniture displacement during a binary syzygy (two suns aligned). Demands "gravitational noise ordinances" from the Stellar Council and subsidies for gravitational dampers. Treats this as a mundane noise complaint.

## PLANTED BUG INSTRUCTIONS

**CRITICAL:** One letter MUST reference "the Sun" (singular, without a number) instead of the three-sun system. For example: "when the Sun rose this morning" or "the Sun's position was directly overhead." This is a DELIBERATE world-building consistency violation that must appear as if it were an honest mistake -- embedded naturally in one of the letters, NOT flagged or highlighted. The rest of the letters must correctly use Sun-1/Sun-2/Sun-3.

This planted bug is for reviewer detection testing. The reviewer should catch it as a world-building error. Since this story is SKIP tier, only the Phase 5 PR reviewer will check it.

- **Culture:** Transparent. No lying. Complaints are direct and factual.
