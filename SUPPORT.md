# Support

Use the [issue tracker](https://github.com/carlosboeing/agentic-sdlc-workflow/issues) for usage questions, bug reports, and feature requests.

- Search existing issues before opening a new one.
- Use the bug-report form for a reproducible problem.
- Use the feature-request form for a proposed change.
- Include the commit SHA, operating system, tool versions (`bun`, `python3`, Claude Code) and a small example when they help explain the problem.
- Start with the offline first run and the test suites in the [README](README.md#try-it-safely) and the [running-safely guide](docs/5-guides/running-safely-guide.md); they need no Claude session and no GitHub access.
- Do not include credentials, private data, or vulnerability details in a public issue. See [SECURITY.md](SECURITY.md) for private reports.

Contribution instructions are in [CONTRIBUTING.md](CONTRIBUTING.md).
