## Story: Add briefing config section

**Blocked by:** none

**Branch:** `e01-s01/briefing-config`

### What

Add the `briefing` section to `.claude/agentic-sdlc-config.json`, following the schema from the design doc (section 4.4). This provides the `defaultDepth` and per-source toggle configuration that the skill file will reference.

### Files to modify

- `.claude/agentic-sdlc-config.json` -- add `briefing` section after `reviewStrategy`

### Config schema to add

```json
"briefing": {
  "defaultDepth": "standard",
  "sources": {
    "roadmap": true,
    "changelog": true,
    "retroDocs": { "enabled": true, "maxCount": 2 },
    "lessonFiles": { "enabled": true, "severityThreshold": "high" },
    "designDocs": true,
    "planDocs": true,
    "retroRecommendations": true,
    "openPRs": true,
    "board": true,
    "stateFile": true,
    "reviewerComments": true,
    "gitLog": false
  }
}
```

### Acceptance criteria

- [ ] `.claude/agentic-sdlc-config.json` contains a `briefing` section with `defaultDepth` and `sources` fields
- [ ] The JSON is valid (passes `jq .` validation)
- [ ] Default values match the design doc: `defaultDepth: "standard"`, all sources enabled except `gitLog`
- [ ] Existing config sections (`github`, `boardStatus`, `modelRouting`, `pm`, `workflow`, `reviewStrategy`) are unchanged
- [ ] No new scripts or library changes required -- this is config-only

### Test plan

- Run `jq .briefing .claude/agentic-sdlc-config.json` and verify output matches schema
- Run `jq . .claude/agentic-sdlc-config.json` to confirm full file is valid JSON
- Verify no existing fields were altered by diffing against main
