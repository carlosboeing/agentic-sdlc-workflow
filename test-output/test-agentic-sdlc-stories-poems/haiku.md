# Haiku Collection: Languages of the Machine

Seven haikus celebrating the soul of programming languages — each in strict 5-7-5 syllable form.

---

### 1. C#

```
Sharp edges define
objects dance in managed fields
garbage fades to null
```

*C#'s managed runtime quietly cleans up after us, like a language that tidies the room when we leave.*

---

### 2. Python

```
Whitespace is the law
indentation guards the gates
simple hides the depth
```

*Python's enforced indentation makes readability a structural requirement, not a suggestion.*

---

### 3. Rust

```
Borrow, do not take
the compiler guards the door
no leaks shall escape
```

*Rust's ownership model turns memory safety from runtime prayer into compile-time certainty.*

---

### 4. JavaScript

```
Loose types shift like sand
callback chains stretch to the sky
undefined is fine
```

*JavaScript's dynamic typing and asynchronous nature create a landscape where anything goes — including undefined.*

---

### 5. Go

```
Goroutines take flight
channels pass the word along
simple runs at scale
```

*Go strips away ceremony so concurrency becomes as natural as passing a note between threads.*

---

### 6. Haskell

```
Pure functions compose
monads bind the world outside
no side effects here
```

*Haskell treats computation as mathematical transformation, quarantining the messy real world behind monadic walls.*

---

### 7. SQL

```
Tables join at dawn
where clauses filter the truth
select what you need
```

*SQL reads like a polite request to a database — declarative, precise, and always starting with what you want.*
