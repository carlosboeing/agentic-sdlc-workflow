## Tech Glossary

| Tech Term | What It Actually Means | In the Show |
|-----------|------------------------|-------------|
| Merge conflict | Two people edited the same file simultaneously and now nobody agrees whose version is correct | A tango. An actual tango. |
| CI/CD | Automated system that checks your code after every change | "Constantly Irritating / Continuously Disappointing" |
| Technical debt | Quick code fixes that create bigger problems later — like clutter you promise to sort out eventually | The ensemble of dancers who won't stop falling |
| Rebase | Tidying your code history retroactively to hide the chaos | The trigger for Act I Scene 3's rock anthem |
| Standup | A 15-minute daily meeting where everyone reports status | A four-minute power ballad |
| Sprint | A two-week work cycle with ambitious goals and quiet rescheduling | The unit of time in which all tragedy occurs |
| Rollback | Reverting to an earlier version when the new one breaks production | A waltz — some failures deserve elegance |
| Legacy code | Old software nobody fully understands but everyone fears deleting | Six dancers who've been here longer than anyone |
