# Act II, Scene 3: The Ship It Showdown

*The CtrlZ war room. Whiteboard countdown: 47 minutes to deadline. The team stands in a tense semicircle. Through the server room glass, The Legacy Codebase waits.*

**Characters present:** Jordan Chase, Priya Mehta, Marcus Chen, Zoe Kim, Aisha Okafor, Riley Park, The Legacy Codebase

---

**JORDAN:** We ship in 47 minutes. The investors are watching.

**AISHA:** I have 14 open P0s. That is not a metaphor.

**RILEY:** Should we maybe... not ship?

**PRIYA:** It's on the roadmap.

*The Legacy Codebase emerges — each dancer a different legacy module, moving in jerky synchronized choreography.*

---

### Song: "Technical Debt (The Musical Number)"

**Performed by:** The Legacy Codebase (ensemble)
**Style:** Modern dance / hip-hop fusion
**Key:** D minor
**Tempo:** 128 BPM

**[VERSE 1]**
We've been here since the hackathon
When Marcus coded in a haze
He said he'd refactor us
But "later" turned to 600 days

**[CHORUS]**
Technical debt, we keep the lights on
Technical debt, the system lives
Technical debt, we hold each other
Technical debt forgives, forgives

**[VERSE 2]**
The auth module attempts a turn
*A dancer stumbles; others catch them*
A chain reaction ripples out
*Each fall triggers the next — then the ensemble catches itself*

**[BRIDGE]**
Don't refactor now, don't touch the code
We are every shortcut, every backfill
Ship us if you want, we'll hold
We've held before — we'll hold still

**[FINAL CHORUS / TAG]**
Technical debt, we carry forward
Technical debt, the only path
Ship us if you want, we'll hold it
Technical debt — do the math

*The ensemble freezes. Jordan hits deploy. Silence. Then — the tests pass. The Legacy Codebase straightens up and smiles.*

---

**ZOE:** The tests are passing. All of them.

**AISHA:** *(closing her laptop)* God help us.

*The lights shift to warm gold. Full cast assembles. The investors return from the wings.*
