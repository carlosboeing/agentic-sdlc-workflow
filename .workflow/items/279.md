## Metadata

**Epic:** E02 — Orchestrator Phase Restructuring and Convention Updates
**Blocked by:** #278 (E02-S01: Rewrite orchestrator.md phases)
**Branch:** `e02-s02/claude-md-dispatch-update`

## Description

Update the Dispatch Protocol section and related cross-references in `CLAUDE.md` to reflect the new 7-phase model and tiered review strategy. This is the convention propagation story — ensuring CLAUDE.md is consistent with the rewritten `orchestrator.md`.

**Key constraint:** No references to builders dispatching reviewers should exist. The orchestrator dispatches all agents directly.

## Files to modify

- `CLAUDE.md` — update Dispatch Protocol section, add reviewStrategy config documentation, update phase references throughout

## Acceptance Criteria

- [ ] The "In-session dispatch (primary)" numbered list is updated to reflect the new wave model:
  - Build dispatch steps remain similar
  - Review step changes to: "Dispatch reviewers in parallel for REVIEW-tier stories; skip SKIP-tier stories"
  - Fix cycle step changes to: "For REQUEST_CHANGES: dispatch fix builders in parallel, then re-reviewers in parallel (max 2 cycles)"
  - Post-build steps renumbered as needed
- [ ] A new paragraph or subsection documents the review tier logic: conditions for SKIP (enabled + difficulty <= maxDifficulty + label match), default behavior (all stories reviewed when disabled)
- [ ] The `reviewStrategy` config schema is documented (fields, types, defaults)
- [ ] The `CFG_SKIP_REVIEW_*` variables are listed in the config.sh variables documentation
- [ ] All stale phase number references in CLAUDE.md are updated or removed (no operational "Phase 5" for builder dispatch, "Phase 6" for review, etc.)
- [ ] The "Parallel dispatch" paragraph mentions parallel reviewers and parallel fix cycles (not just parallel builders)
- [ ] The `review_tier` field is documented where state file dispatch log format is discussed
- [ ] No references to builders dispatching reviewers exist anywhere in CLAUDE.md

## Test Plan

- Search for stale phase references: `grep -n "Phase [5-9]" CLAUDE.md` — verify each match is intentional context, not operational
- Search for review tier docs: `grep -n "review_tier\|reviewStrategy\|SKIP.*tier\|REVIEW.*tier" CLAUDE.md` returns matches
- Search for config vars: `grep -n "CFG_SKIP_REVIEW" CLAUDE.md` returns at least one match
- Verify no builder-dispatches-reviewer: `grep -ni "builder.*dispatch.*reviewer" CLAUDE.md` returns no matches
- Cross-reference: compare CLAUDE.md dispatch steps with orchestrator.md phases for consistency
